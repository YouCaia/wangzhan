============================================
  作品图片 / 视频 放置说明（最新版）
============================================

结构：images/类目/产品名/ 下放主图和 A+，网站自动读取，
绝大多数情况不用改代码（新增作品才需要在 works.html / index.html 加一条）。

============================================
一、头像与微信二维码
============================================
推荐网页上传（免改文件）：
  - 首页左侧头像 → 点击 → 选图 → 自动保存
  - 联系区"获取微信二维码" → 弹窗 → 上传二维码
手动放文件：
  images/avatar.jpg        ← 头像
  images/wechat-qr.jpg     ← 微信二维码

============================================
二、首页背景图（双图滚动交叉淡入）
============================================
  images/hero-bg.jpg     ← 第一张（打开页面时显示）
  images/hero-bg-2.jpg   ← 第二张（向下滚动后淡入）
尺寸建议 1920*1080，两张风格相近切换更自然。

============================================
三、作品图片与视频（中文类目 / 产品文件夹）
============================================
按类目建文件夹，再按产品建子文件夹：

  images/
    美妆/
      美白霜/
        z1.jpg        ← 主图1（1:1，自动当封面）
        z2.jpg
        ...
        z8.jpg        ← 最多 8 张
        video-1.mp4   ← 主图里的视频（可选，顺序任意）
        a1.jpg        ← A+（970*600 或 1460*600）
        a2.jpg
        a-video-1.mp4 ← A+ 里的视频（可选）
      口红/
        z1.jpg
        ...
    3D渲染/
      智能家居/
        z1.jpg
        ...
    A+页面/
    产品建模/
    品牌视觉/
      ...（按你的实际类目继续建）

要点：
  - 数量灵活：主图 / A+ 放几张就显示几张，没放的自动留空（不显示、不裂图、不占位），
    绝不要为了凑满而复制同一张图——网站会自动探测并跳过不存在的文件。
  - 类目 = 文件夹第一级（美妆 / 3D渲染 ...），也是网站的筛选标签
  - 产品 = 文件夹第二级（美白霜 / 口红 ...）
  - 主图统一命名 z1.jpg、z2.jpg ...（不是 main-1）
  - A+ 统一命名 a1.jpg、a2.jpg ...
  - 视频：主图里叫 video-1.mp4，A+ 里叫 a-video-1.mp4，自动识别播放

============================================
四、添加新作品（两处都要加一条）
============================================
【1. 作品集页面 works.html】在 works 数组末尾加一条：

    {
      title: '美白霜主图设计',
      category: '美妆',                 ← 类目（=文件夹第一级）
      tags: '标签1 · 标签2 · 标签3',
      desc: '作品描述文字...',
      folder: '美妆/美白霜/',            ← 文件夹路径（中文）
      main: ['z1.jpg','z2.jpg','video-1.mp4','z3.jpg'],  ← 主图+视频混排，顺序即展示顺序
      aplus: {
        mode: 'seamless',               ← seamless=无缝 / gapped=有缝
        images: [
          { file: 'a1.jpg', width: 970 },
          { file: 'a-video-1.mp4', width: 1460 },
        ]
      }
    },

【2. 首页精选 index.html】在 workData 加一条（结构一致）：

    'work7': {
      title: '新作品标题',
      category: '美妆',
      folder: '美妆/新作品/',
      main: ['z1.jpg','z2.jpg'],
      aplus: { gap: 'seamless', images: [{ file: 'a1.jpg', width: 970, height: 600 }] },
      desc: '作品描述...'
    }

提示：中文文件夹路径网站会自动编码（encodeURI），部署到 Vercel 后也能正常加载。

============================================
五、A+ 有缝 / 无缝
============================================
  mode / gap: 'seamless'   ← 无缝衔接，图片紧挨、无间隔无圆角
  mode / gap: 'gapped'     ← 有缝，图片间留 16px 间隔、带圆角
每张 A+ 宽度：
  width: 970   → 970*600
  width: 1460  → 1460*600

============================================
六、格式与大小建议
============================================
图片：
  - 格式 .jpg / .png
  - 主图 1000*1000px 以上，严格 1:1 正方形
  - A+ 严格 970*600 或 1460*600，别改比例
  - 每张 ≤ 2MB，加载更快
视频：
  - 格式 .mp4（最通用，推荐）/ .webm / .mov
  - 建议 H.264 编码，时长 5~15 秒，体积 ≤ 10MB
  - 竖版横版都行，详情页自动适配

============================================
七、放好之后
============================================
本地预览直接刷新：
  首页:       http://localhost:8080
  作品集:     http://localhost:8080/works.html
线上（部署后）刷新对应公网链接即可。
文件没放就自动留空（不显示、不裂图、不占位），放几张显示几张，绝不重复——不用为了凑数复制同一张图。

============================================
八、分类怎么定？
============================================
category 字段 = 文件夹第一级。多个产品同分类会自动归到同一筛选标签并显示数量，
例如"美妆"下既有美白霜又有口红，筛选栏"美妆"会显示数量 2。
